## Orkas — your AI team on the desktop

Tell the **Commander** what you need. It handles the work directly or brings in specialist agents, then returns the files and results for your review.

- **Deliver real work:** research reports, articles, slide decks, spreadsheets, websites, code and videos.
- **Keep projects moving:** shared context across conversations, to-dos, Auto-advance and scheduled automations.
- **Work with your existing agents:** bring Claude Code, Codex, OpenCode, OpenClaw and Hermes-Agent into the same team.
- **Choose your model:** use the packaged app's built-in model, your own provider keys or a local endpoint. Conversations and files stay on your computer by default; cloud sync is optional in the packaged app.

## VideoStudio — video production for your AI agent

Turn a brief, script or existing footage into a video through natural-language instructions. **VideoStudio is built into Orkas and also available as a standalone toolkit** for agents that can run shell commands or use MCP.

- **Compose:** create explainers, product demos and motion graphics from scripts and assets.
- **Edit:** cut and combine footage, select highlights, add captions, dub and mix audio.
- **Generate when needed:** add AI images, video clips and narration using your own provider keys.
- **Revise and keep control:** edit scene order, text, captions and assets in a readable timeline, then render and check the finished file while preserving earlier deliveries.

> "Turn my product script and screen recordings into a 30-second vertical demo with captions and a voiceover. Keep the scenes editable for revisions."

**[Get VideoStudio](https://github.com/Orkas-AI/Orkas-VideoStudio)** · [Installation](https://github.com/Orkas-AI/Orkas-VideoStudio#install) · [Example workflows](https://github.com/Orkas-AI/Orkas-VideoStudio#use-cases)

Composition and local editing need no paid provider keys. AI generation and synthesized narration require your own configured providers when using the standalone toolkit.
